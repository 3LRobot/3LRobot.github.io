# BellaBot Pro

С завершением жизненого цикла базового **BellaBot** PUDU представляет флагманскую модель **BellaBot Pro**. Переход на модифицированную операционную систему **Pudu OS** позволило исправить основные недостатки и добавить ключевые новшества: большой дисплей для аудио- и видеоконтента, а также набор **AI-функций** для сегмента **HoReCa**. Улучшена стабильность работы многих функций робота, а так же упрощено взаимодействие владельца точки для гибкой настройки и мониторингом за точкой.
![BellaBotPro](/assets/images/BellaBotPro/pudu_bellabotpro.png){: width="200px" style="display: block; margin: 0 auto"}

Модель для глобального рынка существует в двух вариантов цветов: черный и белый.
