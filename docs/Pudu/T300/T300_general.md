# О роботе

PUDU T300 - грузовой робот-доставщик для малых внутрескладских операций по транспортировке грузов в промышленных условиях. Робот оснащен системой автоматической навигации поддерживающей мультиэтажные строения, автономно взаимодействуя и пользуя лифтом. Робот способен преодолевать 2см перепады высот поверхностей и щели до 35 мм для обеспечения безопасного перемещния по инфраструктуре склада. Робот поддерживает модульную систему адаптации под склад, такие как: тележка и лебедка для буксирования, конвеерная лента с регуляровкой высоты, стелажи для Robotics Warehouse managment system. В функции робота входит электромеханическое ассистирование при его транспортировке вручную для облегчения перемещения робота с грузом и без по территории. Опираясь на данные камер и лидара может выполнять следование за человеком в неизвестной среде.

При весе в 65кг в базовой комлпектации робот способен транспортировать до 300кг в течение 6 часов, или около 12 часов без нагрузки. Робот оснащается быстросъемным ёмким аккумулятором 30Ач. Робот оснащён внешними контактами для беспроводной зарядки, вместе с контактной зарядной станцией робот может автоматически отправляться на зарядку при низком уровне заряда или во время простоя, чтобы поддерживать высокий уровень заряда аккумулятора.
