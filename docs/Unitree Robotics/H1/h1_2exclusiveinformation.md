# Спецификация

В сравнении со стандартным роботом **H1** у версии **H1_2** повышенное количество степеней свобод, за счет дополнительных степеней свобод в руке в области предплечья, а так же в ступнях и голени. Итого робот имеет 27 степеней свобод позволяя совершать более точные движения. Однако получил больший вес, за счет добавления новых моторов для обеспечения этой мобильности.

![Спецификация](/assets/images/h1_2specs.png){: width="600px" style="display: block; margin: 0 auto"} 

Индексы ID моторов можно найти по следующей [ссылке](https://support.unitree.com/home/en/H1_developer/H1-2_Joint_motor_sequence) , всегда требуется **актуализация** данных при обновлении **unitree_sdk2**.

![Индексация](/assets/images/h1_2jointname&id.png){: width="600px" style="display: block; margin: 0 auto"} 

## Интерфейсы подключения

Интерфейсы для подключения дополнительной периферии находятся с правой стороны торса робота.

![Интерфейсы](/assets/images/h1_2sideiface.png){: width="600px" style="display: block; margin: 0 auto"} 

## Элементы информационной сети

Каждый хост имеет за собой отдельный зарезервированный IP в собственной подсети 192.168.123.0/(24)

При установке данных адресов разработчик не сможет получать ответ от участников подсети

| Название хоста                                                       | IP-адрес                                                        |
|----------------------------------------------------------------------|-----------------------------------------------------------------|
| PC1 Системный ПК без прямого доступа                                 | 192.168.123.161                                                 |
| PC2 Основной ПК разработчика                                         | 192.168.123.164                                                 |
| PC3 Дополнительный ПК разработчика,  вне зависимости от конфигурации | 192.168.123.163                                                 |
| LiDAR                                                                | 192.168.123.120 в старых версиях 192.168.123.20 в новых версиях |

Не рекомендуется изменять стандартные сетевые настройки для устройств из данной таблицы, в случае неполадок используйте образ восстановления к заводским настройкам для соотвествующего PC
