# H1


Модель **H1** - это двухопорный робот-гуманоид, являющийся программно-аппаратным комплексом для профессиональной разработки и создания пользовательского функционала. Может использоваться в качестве платформы для обучения программированию бионических роботов и исследований.

![Общий вид H1](/assets/images/h1.jpg){: width="400px" style="display: block; margin: 0 auto"}

Программирование робота осуществляется на языке С++. Возможна разработка собственных сценариев движения и различных режимов автономной работы, изменение бионики движения (походки) и т.п. 

Благодаря большому количеству интерфейсов возможно подключение специального оборудования и датчиков. Устройство может быть запрограммировано для выполнения множества функций, например геодезическая оцифровка местности и манипуляции объектами (с установкой кистей для операций с мелкой моторикой), может применяться для разработок в области искусственного интеллекта. Робот поставляется вместе с **SDK** (пакет _unitree_sdk2_), так же имеется программный слой для управления из под фреймворка **ROS2** (пакет _unitree_ros2_).


Поставляется в одной модификации - **Edu**.

# H1_2

Модель **H1_2** - идеологическое продолжение крупногабаритного робота-гуманоида, получившего ключевые улучшения конструкции на основе опыта младшей гражданской модели робота G1 в обертке мощных электродвигателей собственной разработки Unitree M107, что, в первую очередь, позволило увеличить максимальную грузоподъемность одной руки до 7 кг, а так же уменьшить износ моторов тазового сустава, за счет уменьшения паразитных вибраций в виду неудачного дизайна базовой модели.

Вторым по важности улучшением можно считать смену и маскировку коннекторов и всех проводов, которые в стандартной модели были снаружи во внутрь корпуса, что кратно увеличивает надежность соединений от внешний воздействий и случайных коллизий с самим собой.


![Общий вид H1_2](/assets/images/h1_2.jpg){: width="400px" style="display: block; margin: 0 auto"}

По аналогии с прародителем доступен в вариациях с различными кистями от Unitree Dex5-1, от Inspire Robotics, от BrainCo подвязанных в управление единым протоколом RS485 по всему роботу, **исключая** перекрестные решения в **сравнении с H1**. С возможностью установки дополнительного вычислительного модуля для разработчиков, включая флагманские решения на базе Nvidia AGX Thor.
