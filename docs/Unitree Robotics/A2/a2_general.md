# A2

**Unitree A2** - промышленный четырехопорный робот для инспекции, логистики, аварийно-спасательных сценариев и задач вторичной разработки.

Линейка включает версии **A2** и **A2-PRO**, а также колесно-шагающую конфигурацию **A2-W**. Робот использует две быстросъемные батареи, поддерживает горячую замену и рассчитан на подключение внешнего оборудования для задач автономной навигации, мониторинга, транспортировки и пользовательской разработки.
