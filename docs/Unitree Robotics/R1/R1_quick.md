# Начало работы

 Аккумулятор робота для безопасности может быть переведет в **режим транспортировки** для исключения произвольного запуска в роботе.
 
Светодиоды аккумулятора при попытке активировать его будут перемигивать желтым цветом. Для вывода аккумулятора требуется разово подключить его к зарядному устройству.

## Запуск робота
Вставьте аккумулятор в отсек под левой рукой робота.

Подняв левую руку ориентируйте и совместите угол склона корпуса аккумулятора и уклон торса. Затолкните аккумулятор с небольшого рывка, в результате защелки полностью раздвинутся и аккумулятор зафиксируется в отсеке робота.

Запустите аккумулятор робота **двойным нажатием** - быстро кликните один раз, после удерживайте более 3 секунд. Светодиод перемаргнет и будет постоянно гореть отображая уровень заряда зеленым цветом.

 Для выключения зажмите кнопку включения на аккумуляторе на 5 секунд.
Обратите внимание на светодиод в треугольнике на грудной пластине робота, который отображает текущий статус загрузки.

Пульсирующий бирюзовый  -  загрузка

Фиолетовый  -  без тока на моторах (Zero Torque)

Оранжевый  -  режим Damping

Белый  -  режим бега

Темно-синий  -  режим устойчивой позы

Красный  -  критические ошибки, проверьте приложение

Желтый  -  режим отладки/разработки(отключен базовый сервис походки)

### Запуск на полу

Робот R1 инициирует калибровку при включении, поэтому перед включением робота 

1. Расположите лицом вверх горизонтально.
![Запуск с пола](/assets/images/R1_liestartup.png){: style="display: block; margin: 0 auto"}
2. Запустите аккумулятор  
3. Во время загрузки робот повернет голову и светодиод загорится фиолетовым цветом - робот загрузился.
4. Включите пульт R3-1 двойным нажатием, по аналогии с включением робота.
5. Вызовите команду L2 + ВВЕРХ, чтобы напрячь моторы робота.
6. Зажмите комбинацию L2 + X (4 секунды) и робот автоматически поднимится из положения лежа в устойчивое положение стоя.
7. Для того, чтобы перевести робота в режим ходьбы/бега нажмите R2 + A.

После этого зайдите в приложение создайте свой аккаунт для привязки робота. Поставьте галочку напротив текста: _please review and agree the Privacy Policy, the Terms of Service and the Legal Statement_, и нажмите Sign up.

![Схема собаки](/assets/images/explore_login.jpg){: style="display: block; margin: 0 auto"}

Введите ваш _email_ и код с картинки.

{: .note}
Рекомендуем не использовать **доменные и корпоративные** почтовые адреса и при создании аккаунта отдать **предпочтение** почтовым ящикам __@gmail.com__.

![Регистрация](/assets/images/explore_signup.png){: style="display: block; margin: 0 auto"}

Укажите контактные данные компании.

![Контактные данные](/assets/images/explore_signupcompany.jpeg){: style="display: block; margin: 0 auto"}

Установите пароль для аккаунта на латинице

![Указание пароля](/assets/images/explore_setpasswd.jpg){: style="display: block; margin: 0 auto"}

Войдите в Ваш аккаунт и нажмите _Add robot_. Выберите вашего R1.

![Добавление робота](/assets/images/explore_addrobot.jpg){: style="display: block; margin: 0 auto"}

И режим подключения к роботу. Режим Wi-Fi предпочтителен.

![Передача данных сети](/assets/images/reg_last.png){: style="display: block; margin: 0 auto"}

Приложение используя Bluetooth передаст роботу указанные данные, и робот будет передавать свой уникальный идентификатор в облако Unitree, чтобы привязаться к аккаунту. Если все прошло хорошо, то робот будет привязан к аккаунту.

![Регистрация в облаке](/assets/images/reg_fin.png){: style="display: block; margin: 0 auto"}

{: .note}
При невозможности подключения к Wi-Fi используйте AP mode. Проблема с регистрацией робота в облаке в нашем регионе может возникать на сетях Интернет.

### Привязка пульта

1. В приложении перейдите в раздел **[Device]-[Data]-[Remote Control]**
2. Найдите на пульте стикер с кодом
![Стикер](/assets/images/r3sticker.jpg){: style="display: block; margin: 0 auto"}
3. Введите в поле binding код со стикера **до тире** (например: 34433К)
![Привязка пульта](/assets/images/r3bind.png){: style="display: block; margin: 0 auto"}
4. Проверьте успешность привязки выполнив любую команду, перезапуск пульта не требуется.
