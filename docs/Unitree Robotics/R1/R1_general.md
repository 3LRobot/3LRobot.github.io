# Общая информация

Робот R1 - продолжение серии небольших гуманойдных робот от Unitree Robotics. По модели классически робот разделяется на упрощенную версию, с меньшими степенями свободы, укороченным гарантийным периодом, а так же продвинутую версию, которая поддерживает вторичную разработку и оснащается вторым компьютером.
